# 정비소 배치 문제 — 강화학습 실습

정비소 3개(A, B, C)와 최대 3대까지 대기하는 공간이 있습니다. 매 틱마다 대기 중인
차량 하나를 골라 비어 있는 정비소에 배치하거나, 아무것도 하지 않습니다.
**총 100대를 최소한의 시간에 정비 완료하는 것이 목표입니다.**

```
점수 = 소요 틱 수 + 50 × 이탈 차량 수        (낮을수록 좋음)
```

차량은 인내도가 0이 되면 떠나고(이탈), 그만큼 점수에 벌점이 붙습니다.

## 설치

```bash
python -m venv .venv
```


## 두 개의 문제

| | 문제 1 | 문제 2 |
|---|---|---|
| 도착 간격 | 0~30 틱 | 없음 (매 틱) |
| 인내도 | 30 | 100 |
| A 정비소 | 20~25 | 22~23 |
| B 정비소 | 20~25 | 21~24 |
| C 정비소 | 20~25 | 10~27, 크기≤4.0 시 50%↓ |
| 베이스라인 점수 | 915.4 | 630.4 |

**문제 1** 은 세 정비소가 완전히 같습니다. 어디에 넣어도 결과가 같으므로
점수를 낮출 방법이 없습니다. 이 문제의 목적은 **여러분이 만든 관측과 보상으로
학습이 실제로 돌아가는지 확인**하는 것입니다. 베이스라인 근처면 통과입니다.

**문제 2** 부터 정비소마다 잘 맞는 차량이 달라집니다. 어떤 차를 어디에 넣는지가
총 소요 시간을 바꿉니다. 베이스라인 630.4 보다 낮추는 것이 목표입니다.

## 학습 진행 상황 읽기

`train.py` 는 10% 단위로 한 줄씩 진행 상황을 찍습니다.

```
[level 2] 관측 차원 21, total_timesteps 500,000, n_steps 2048, ent_coef 0.01
  베이스라인 631.2 (규칙 기반, 낮을수록 좋음)
     진행        스텝      경과      잔여       평균보상      점수추정       대비
    10%    50,000    0:12    1:56       -5.1     678.6    -7.5%
    50%   250,000    1:06    1:06       97.8     572.4    +9.3%
   100%   500,000    2:12    0:00       97.5     553.0   +12.4%

  학습 시간 2분 13초 (3745 steps/s)
```

| 열 | 뜻 |
|---|---|
| 평균보상 | 여러분이 설계한 보상의 에피소드 평균 |
| 점수추정 | **실제 평가 지표** (5 에피소드 실측) |
| 대비 | 베이스라인 대비 개선폭. `+` 면 베이스라인보다 좋음 |

**두 열을 같이 보세요.** 평균보상이 오르는데 점수추정이 안 내려가면,
여러분의 보상 함수가 목표와 다른 것을 최적화하고 있다는 뜻입니다.

학습 시간은 대략 이렇습니다 (CPU 1스레드 고정).

| `total_timesteps` | 시간 |
|---|---|
| 100 (기본값) | 4초 |
| 100000 | 28초 |
| 500000 | 2분 13초 |

## 자주 막히는 지점

- **관측 값은 반드시 `[0, 1]` 범위여야 합니다.** 벗어나면 실행 즉시 오류로 알려 줍니다.
- **인내도는 문제마다 다릅니다** (문제 1은 30, 문제 2는 100).
  `100` 을 하드코딩하지 말고 `env.max_patience` 로 나누세요.
- **`config/ppo_config.json` 의 기본값으로는 학습이 되지 않습니다.**
  `total_timesteps` 부터 확인하세요.
- 학습이 되고 있는지는 tensorboard 의 `rollout/ep_rew_mean` 곡선으로 판단합니다.
